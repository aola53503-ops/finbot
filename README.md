# 🏦 FinBot - Your Intelligent Banking Assistant

Track, budget, and grow your wealth with FinBot - the smart Telegram banking assistant.

## ✨ Features

- 💰 **Track Income & Expenses** - Log transactions instantly
- 📊 **Auto-Categorization** - Organized spending categories
- 📈 **Budget Management** - Set and track monthly budgets
- 📉 **Spending Analytics** - Visual insights and trends
- 🔔 **Smart Alerts** - Budget warnings and reminders
- 💳 **Multi-Account** - Manage multiple accounts
- 📋 **Transaction History** - Searchable history
- 🎯 **Savings Goals** - Set and achieve goals
- 💡 **Financial Advice** - AI-powered insights

## 📋 Commands

- `/start` - Main menu
- `/setbudget "Category" Amount` - Set monthly budget
- `/setgoal "Goal" Amount YYYY-MM-DD` - Set savings goal
- `/cancel` - Cancel current operation

## 🚀 Quick Start

1. Create bot with @BotFather
2. Clone repository
3. Add BOT_TOKEN to Railway
4. Deploy!
